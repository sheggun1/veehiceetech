# Website images

Upload the website's replacement photographs and graphics into this folder.

## Fixed filenames

Use these filenames when replacing the matching website image:

- `hero.jpg` — homepage hero/banner
- `vicora.jpg` — VICORA product section
- `services.jpg` — services section
- `marketplace.jpg` — marketplace section
- `about.jpg` — about/company section
- `portfolio-1.jpg`, `portfolio-2.jpg`, etc. — portfolio project images

## Replacing an image

Upload the new image using the exact same filename and path, then commit the change. Keep the file extension the same too. For example, replace `hero.jpg` with another image named `hero.jpg`.

Recommended formats: JPG, PNG, or WebP. Use reasonably compressed images (ideally under 1–2 MB each).

Note: Adding images to this folder does not automatically change the live website until the website's image references are configured to use these paths. Existing site images remain unchanged until that integration is completed.
